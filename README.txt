Pweper Bot — установка:
1. cp .env.example .env && nano .env  (заполни TOKEN, API_ID, API_HASH, ADMIN_IDS)
2. sudo cp bin/astcenc /usr/local/bin/astcenc && sudo chmod +x /usr/local/bin/astcenc
3. source .env && ./pweper-bot

AI (опционально):
- ONLYSQ_API_KEY=твой_ключ (для /aicolor, /imgdescribe, /img2prompt)
- Текст: gemini-3.5-flash | Картинки: nano-banana
